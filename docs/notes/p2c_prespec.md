# P2c 事先指定（2026-10-25，跑之前寫好；結果出來後不准改，要改就另起 v2 並記錄理由）

## 目的
P2b 結果：不通訊的 DOB 在追蹤上勝過分享。紅方指出 DOB 的量測太乾淨：IMU 是真值速度的有限差分，加 0.15 m/s² 白噪聲，推力量測精確。
P2c 回答兩個問題：
(Q1) 在較真實的感測條件下，DOB 的優勢還在不在？
(Q2) 「共享模型預測未來張力＋本地 DOB 修正當下偏差」的混合法，能不能勝過最強的本地方法？分享在混合法裡的貢獻有多大？

## 感測 profile（三級，事先固定）
| profile | IMU 白噪聲 σ_a | IMU 偏差 | IMU 延遲 | 推力係數誤差（每機固定，未知） | 繩方向雜訊 |
|---|---|---|---|---|---|
| clean | 0.15 m/s² | 0 | 0 | 0 | 0.005 rad |
| moderate | 0.6 m/s² | 隨機漫步，穩態約 0.1 m/s²（0.3 N 等級） | 2 控制步（20 ms） | ±5% 均勻 | 0.01 rad |
| harsh | 1.5 m/s² | 同上 ×2 | 3 控制步 | ±10% 均勻 | 0.02 rad |
理由：多旋翼上的 MEMS 加速度計受馬達振動影響，未濾波的雜訊常在 0.5–2 m/s² 等級；推力係數的標定誤差常在百分之幾。這些是假設值，論文中要標成假設，並在 PREREG 中再核對文獻。

## 方法
- 本地（不通訊）：DOB、LS、LSN、HYB-local（IND-δm 模型預測＋DOB 修正）
- 共享：CEN-ATT、CON-ATT（path 圖，每步 2 次迭代，通訊理想）、HYB（CEN-ATT 模型預測＋DOB 修正）
- 參考：NOM、ORACLE
- 混合法的定義：T̂_i(t+k) = T_model,i(t+k) + r_i(t)·exp(−k·dt/τ)，其中 r_i = LPF[T_DOB,i(t) − T_model,i(t)]。τ 與 LPF 頻寬只用調參 seeds 調。

## 主要比較（事先指定，只看這幾個下結論）
1. HYB − best_local：每個 profile × 速度倍率一格。best_local 是在調參 seeds 上 RMSE 最佳的本地方法，選好之後固定。
2. HYB − HYB-local：分享在混合法中的純貢獻。
3. DOB − CEN-ATT：Q1。
其他比較都只當描述。報 95% seed bootstrap CI，也報 Holm 校正後的結論。

## 條件與 seeds
- 速度倍率 {1.0, 1.5}；軌跡 circle、fig8；N=3；無風；通訊理想。
- 調參 seeds 2020–2029（每個 profile 各自重調 DOB／LS 的濾波，以及 HYB 的 τ）；評估 seeds 2100–2119（新的、獨立）。不准碰 3000 以上。
- 診斷（不算結論）：×1.5 時，ORACLE 改用 payload 實際加速度做前饋，看能不能追上 DOB。

## 判定規則
- 只要有任一 profile × 速度格，HYB − best_local 的 CI 整段 < 0，就說「在 X 條件下，分享＋本地回授有用」，同時報告所有不成立的格子。
- 全部格子都不成立，就說「在測過的範圍內，分享不值得」，作為界線結果。
