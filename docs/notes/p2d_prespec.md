# P2d 事先指定（2026-10-30，跑之前寫定；之後不改，偏離寫在 PROGRESS）

目的：PREREG 定稿前補三件事（使用者 2026-10-30 決定，目標先投 workshop）：
1. 感測強度掃描：找出「分享比本地好」開始成立的分界。
2. 改用分散式分享（CON-ATT，鄰居交換），並做掉包小掃描。
3. 補更強的本地基線：帶 IMU 偏差狀態的本地 EKF（EKF-L），所有方法用相同的調參預算。

這一段全部是 pilot，不當正式結論。正式結論在 PREREG 定稿後，用 seeds ≥3000 重跑。

## 調參
- 預算：每個方法在 seeds 2020–2024 上最多試 8 組超參數，在 moderate×1.0 調一次後，所有格共用。
- 邊界規則：選到邊界時延伸一次，然後停。
- CEN-ATT 和 CON-ATT 共用同一組超參數。

## 感測強度掃描
- 比例 s ∈ {0, 0.5, 1, 1.75, 2.5}。s=0 是 clean，s=1 是 moderate，s=2.5 約等於 harsh。
- 隨 s 線性放大的量：IMU σ、偏差、推力係數誤差、繩方向雜訊。延遲：s<0.5 為 0 步，0.5≤s<1.75 為 2 步，s≥1.75 為 3 步。
- 其他條件：速度 1.0，軌跡 circle 和 fig8，seeds 2200–2219（新的 pilot，之前沒看過）。
- 主要量：Δ(s) = 最佳分享法 RMSE − 最佳本地法 RMSE。「最佳」由調參 seeds 選定，不看評估結果。

## 掉包掃描
- CON-ATT 在 moderate×1.0 下，掉包率 p ∈ {0, 0.5, 0.9}，每條訊息獨立丟棄。
- seeds 2200–2219。

## 雜訊底線（用來決定 Δ 和每格 n）
- 在調參 seeds 2020–2029 上，量配對差的 seed 間標準差。
- 由此算出：要在 power 0.8 下偵測 Δ 時，每格需要多少 seeds。
- 暫定 Δ = max(0.5 cm, 主比較中本地方法 RMSE 的 10%)。最後由使用者定。

## 報告方式
- 兩條軌跡分開報告。
- RMSE > 1 m 或發散的集，記為 1 m，並另外報成功率。
