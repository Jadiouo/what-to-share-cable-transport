# PREREG 檢定力模擬（腳本 experiments/prereg_power.py 產出）

n = 40 seeds/格；模擬 2000 次；sign-flip 5000 次；種子固定。資料：`results/p2d/sweep.jsonl`（seeds 2200–2219，n=20/格，2 軌跡，hp=best.json），有放回重抽到 n=40，同一組 seed 索引貫穿所有 s、方法、軌跡。這些 seeds 已被看過。EKF-L+GEO 只有 s ∈ {0, 1, 2.5}；s=0.5、1.75 用同 seed 同軌跡的 GEO RMSE 對 s 線性內插（**內插**，標 †；延遲是階梯、pos_std 在 s>1 飽和，內插只是粗估）。

限制：20 個 seed 重抽到 40，有效資訊仍只有 20 個 seed；觀察到的均值本身有抽樣誤差，as-observed 的 power 可能偏樂觀；2200–2219 已被看過；sd 在各 s 的估計各只有 20 個點。檢定力是規劃用，不是證據。

Holm 家族（各 α=0.05，用單尾 p）：F1 = H1a、H1b 各 5 s x 2 軌跡（20 個）；F2 = H2(DOB) x 2；F3 = H3(s=1, TOST ±0.25) x 2；次要：F4 = H2(LOC-M) x 2；F5 = H4(來源交叉斜率) x 2；F6 = H3 在其他 s x 8。某 (假設, s) 成立 = 兩條軌跡都被該家族 Holm 拒絕。
