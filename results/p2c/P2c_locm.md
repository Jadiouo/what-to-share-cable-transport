# LOC-M 對照（exploratory / 事後；不屬於 prespec）

LOC-M = 每機自己的 LocalDm 估 [δm, ζ_i]，`team.set_theta` 模型前饋；沒有 DOB 殘差通道（不設 tension_fn）；`est` 時 `set_eta(i, 1+ζ̂_i)`。與 CEN-ATT 的差別只有估計器（LocalDm 不通訊 vs ReplayCEN 集中式分享）。無超參數調參（LocalDm 預設：prior_dm=0.5、zeta_std=0.3、lam=0.9995，與 CEN-ATT 同 lam；調參預算 0，不多於 CEN-ATT）。

單位 cm；seeds 2100-2119（n=20 配對）；兩軌跡先對 seed 平均；CI = seed 層級 bootstrap 95%；差 = A − B（負 = A 較好）；發散或 RMSE>1 m 記為 1 m。全部為事後分析。每格另列 circle／fig8 分軌跡差。
